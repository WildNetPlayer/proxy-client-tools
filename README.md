## 二、 核心干货：提升连接稳定性与速度的 3 个技巧

1. **启用延迟自动测速与故障转移**
   * 在客户端中配置“自动选择”或“故障转移”策略组。当主用节点突发波动时，客户端会自动切换至当前响应最快的备用节点，避免频繁手动切线。
2. **精细化分流规则（Rule Set）**
   * 确保国内常用服务（如国内 CDN、网银、微信等）走直连，海外开发工具（GitHub、Google、ChatGPT）走代理。合理的分流不仅能节省流量，还能避免本地服务因代理产生冲突。
3. **DNS 防泄漏与 DoH 配置**
   * 开启客户端的本地 DNS 缓存并配置加密 DNS（如 Cloudflare `1.1.1.1` 或 Google `8.8.8.8`），防止 DNS 污染导致的解析超时。
